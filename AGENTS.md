# App
- `src/` - NestJS Starter is a boilerplate for creating a typical NestJS project. It has all the preferred toolings and integrations for it to work as a starting point in any modern API project.
## Docs

- `docs/glossary.md`: Product vocabulary and common domain terms

## Code Style

- Avoid using the `any` type
- Prefer well named intermediate variables over comments

## Notes

- For DB schema or migration changes, edit `src/db/schema` and follow the instructions in `docs/database.md`
